# Diagnostics

Carbide diagnostics are designed to be unusually descriptive (a core product goal). Every error says **what happened, where, why, and how to fix it**.

## Anatomy of an error

```
error[E3006]: unknown variable 'missing'
  --> src/main.carb:2:11
   |
 2 |     print(missing)
   |           ^^^^^^^
   = This name is not a variable in scope.
   hint: Did you mean to call a function? Functions are not values yet (phase 1).
```

- **Code** — stable identifier (`E3006`) for tooling and docs
- **Location** — file:line:column with the exact source line and caret
- **Explanation** — the `=` line
- **Hint** — the `hint:` line with a likely fix

## Runtime panics

Programs can fail at runtime only for a small set of documented reasons:

```
panic: index out of bounds: index 5, length 3
```

Printed to stderr; the process exits with code 1. There is no stack trace yet (planned with debug info).
